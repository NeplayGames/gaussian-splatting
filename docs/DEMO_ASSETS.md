# Demo Assets

The demo manifest is `configs/demo_manifest.json`. It lists the Tanks-and-Temples/Deep-Blending dataset archive plus four model packages: truck/baseline, truck/segs_full, drjohnson/baseline, and drjohnson/segs_full.

Model package checksums and hosting URLs are intentionally marked pending until maintainers train, package, checksum, and host the archives with `scripts/package_demo_models.py` on a local GPU machine. Do not replace these fields with guessed values.
